# DFT-Tools
Density-functional theory methods and analysis tools that I use in my work.

This repository includes:

1) Self-consistent field method for:

- Hartree–Fock method;
- Kohn–Sham method;
- Orbital-Free Kohn–Sham;
- Fractional electron numbers.

All self-consistent codes are made in spin-restricted and unrestricted versions.

2) Analysis tools:

- SCF convergence tools;
- Electron density plotting;
- Energy density plotting (kinetic, exchange, Coulomb, etc.);
- Inhomogeneity parameters plotting (ELF and others); 
- Dissociation curves (+ symmetry breaking);
